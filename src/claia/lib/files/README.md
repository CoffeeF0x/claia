# Files

Abstractions for inputs/outputs (text, image, audio, prompts, manifests, conversations).

Key modules:
- `base.py` — core file types and serialization
- `text.py`, `image.py`, `audio.py` — media-specific helpers
- `prompt.py` — prompt templates/parts
- `manifest.py` — content manifests
- `conversation/` — structured dialog objects
