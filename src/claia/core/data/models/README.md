# Conversation-domain models

`Conversation`, `Message`, and `Prompt` live here. They are **not** IO artifacts.

Artifacts and chunks live under:

- `claia.core.data.artifacts`
- `claia.core.data.chunks`
- `claia.core.data.common` (`DataObject`)
- `claia.core.data.response` (`ModelResponse`)

See `claia/data-architecture.md` in the ExoFox docs repo.
